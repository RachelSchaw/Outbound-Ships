# Foundry Release Notes and Change Log

This directory contains all release notes and change logs for Foundry releases.

## Structure

- Each release should have its own markdown file named with the version number (e.g., `v1.0.0.md`)
- Use the template provided in `TEMPLATE.md` for consistency
- Archive older releases in the `archive/` subdirectory

## Guidelines

1. **Version Naming**: Follow semantic versioning (MAJOR.MINOR.PATCH)
2. **Date Format**: Use ISO 8601 format (YYYY-MM-DD)
3. **Categories**: Organize changes under:
   - New Features
   - Enhancements
   - Bug Fixes
   - Breaking Changes
   - Deprecations
   - Security Updates

## Review Process

All release notes should be reviewed by:
- Product Manager
- Engineering Lead
- Documentation Team

## Publishing

Release notes are published to:
- Internal documentation portal
- Customer-facing release notes page
- Email notifications to subscribers
