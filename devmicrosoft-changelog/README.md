# Dev.Microsoft.Com Change Log

This directory tracks all changes and updates to the Dev.Microsoft.Com platform.

## Structure

- Changes are organized by month: `YYYY-MM/`
- Each entry uses the template in `TEMPLATE.md`
- Major updates get their own dedicated file

## Change Categories

- **Content Updates**: New articles, tutorials, samples
- **Platform Updates**: Site improvements, new features
- **API Documentation**: API reference updates
- **Tool Updates**: SDK, CLI, and tool releases
- **Deprecations**: Sunset announcements
- **Known Issues**: Platform issues and workarounds

## Workflow

1. Create change log entry using template
2. Get approval from content owner
3. Coordinate with DevRel team for publication
4. Update cross-references and related docs
5. Publish and announce through appropriate channels

## Publishing Schedule

- Weekly updates: Every Monday
- Major releases: As scheduled
- Security updates: Immediate

## Stakeholders

- Content Team
- Developer Relations
- Product Management
- Engineering
